APPLY LOKER — PWA

File ini sudah disiapkan sebagai Progressive Web App (PWA), sehingga bisa dipasang sebagai aplikasi di laptop dan HP tanpa membuat ulang aplikasinya.

CARA PASANG
1. Upload isi folder ini ke hosting HTTPS (misalnya GitHub Pages atau hosting statis lain).
2. Buka alamat websitenya di Chrome/Edge (laptop) atau Chrome/Safari (HP).
3. Pilih Install app / Add to Home Screen.
4. Setelah terpasang, Apply LOKER akan tampil seperti aplikasi biasa.

CATATAN
- Data lamaran saat ini tetap disimpan di localStorage perangkat, sesuai kode asli. Jadi data di laptop dan HP tidak otomatis sama.
- Fitur sinkron Google Sheets tetap memakai Web App URL yang diatur dari menu (⋮).
- PWA membutuhkan alamat HTTPS agar browser mengizinkan instalasi.
