Panduan & Cara Pakai Aplikasi Cloud

1. Sinkronisasi Tema Otomatis

Aplikasi otomatis mendeteksi mode gelap/terang dari pengaturan perangkatmu secara real-time. Kamu juga bisa mengaturnya manual melalui menu titik tiga di kanan atas.

2. Notifikasi & Pengingat Follow-Up

Aktifkan izin notifikasi browser untuk mendapatkan pengingat harian otomatis jika ada jadwal follow-up atau deadline lamaran kerja hari ini.

3. Sinkronisasi Cloud (Realtime Database)

Data lamaranmu otomatis tersimpan secara aman di server Firebase. Login dengan email yang sama di HP atau Laptop, datanya akan selalu tersinkronisasi.
