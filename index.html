📖 Panduan & Cara Pakai Aplikasi

1. Menambah Data Lamaran

Klik tombol lingkaran plus (+) di pojok kanan bawah. Cukup isi Nama Perusahaan, Posisi, Tanggal, dan Status. Jika butuh detail tambahan (Gaji, Link, Kontak), klik tombol + Tambah Info Detail.

2. Catatan Harian & Riwayat

Catatan harian otomatis mendeteksi tanggal hari ini. Setiap berganti hari, catatan akan bersih secara otomatis untuk hari baru. Kamu bisa melihat catatan-catatan hari sebelumnya dengan mengklik tombol Riwayat di samping judul catatan.

3. Fitur Unggulan (Ghosting Alert & Konfirmasi Interview)

  • Ghosting Alert: Label peringatan oranye otomatis muncul jika lamaran berstatus Terkirim/Screening sudah >14 hari tanpa kabar.
  • Konfirmasi Interview: Di samping tombol WA, ada tombol opsi pesan cepat untuk konfirmasi kehadiran interview ke HRD secara instan.

4. Menu Titik Tiga (⋮)

Di pojok kanan atas terdapat menu tambahan untuk: Mengatur template surat lamaran, menyinkronkan data ke Google Sheets, mengatur link Web App, serta mengganti Mode Terang/Gelap.
